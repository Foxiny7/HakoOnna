# 箱女藏匿姿势参照箱

8 个 `.glb` 文件，每种容器一个，按游戏里真实的容器预制体生成，已经乘了家具放大倍数 1.25（1 单位 = 房子里的 1 米）。用来在 Blender 里把绑好骨骼的箱女掰进容器。`PoseReference_Overview.png` 是 8 个文件的预览：左边是玩家视角，右边是 3/4 视角。

## 打开

Blender：文件 → 导入 → glTF 2.0 (.glb/.gltf)，选一个文件。建议一个姿势用一个 `.blend`。

## 文件里有什么

| 物体 | 是什么 |
|---|---|
| `Shell` | 不动的板材：背板、侧板、底板、顶板或前板；押入れ还有隔板和固定的那扇纸门，抽屉柜还有下面两层抽屉的面板，長持还有贴在前后两面的铁箍 |
| `Open_Doors` / `Open_Door` / `Open_Fusuma_R` / `Open_Lid` | 打开状态的门、推拉门、盖子 |
| `Drawer_0` → `Open_Drawer_0` | 只有箪笥有：拉开的上层抽屉。抽屉里的姿势要跟着抽屉动，所以把角色设成 `Drawer_0` 的子物体 |
| `SafeZone_1.5cm` | 绿色细杆框：容器关上时身体能占的空间（离墙、门、盖 1.5 cm；可以贴底） |
| `Opening` | 黄色细杆框：玩家看进去的开口 |
| `FaceTarget` | 红色小菱形：美术设定 6.2 姿势表里脸的位置 |
| `PlayerEye` | 摄像机：游戏里打开容器后检视镜头停的位置（眼高 1.58 m，竖直视野 75°），对准 `FaceTarget` |
| `Floor` | 4 × 4 m 的地面 |

## 方向和单位

- 原点 = 容器底面中心 = Unity 里容器的根节点。
- 开口朝 Blender 的 **-Y**：前视图（Numpad 1）正对开口。掀盖类的开口朝上，用顶视图（Numpad 7）。
- 1.2 m 高的角色直接放进来就是游戏里的比例，不用再缩放。
- 墙挡住视线时按 Alt+Z（X 光）。
- 看玩家视角：选中 `PlayerEye`，Ctrl+Numpad 0 设为活动相机，再把渲染分辨率设成 1920 × 1080，画面比例才和游戏一样。眼高按美术设定 6.1 计划的 1.58 m 算；程序那边的 `GameConfig` 现在还是 1.45 m。

## 摆姿势的规则（美术设定 6.5）

- 身体、手脚、头发、和服都要在绿色框里，这样门、盖关上时不会穿模；可以贴底。
- 自己不能穿自己：身体对身体、身体对衣服、头发对身体。
- 抽屉：叠起来不超过 0.33 m（绿色框的高度就是 0.33 m），脸要在拉出来的那一段里。
- 米柜：手扣在边沿下面的内壁，不要扣在边沿上。
- 長持：铁箍只贴在箱子外面（2026-11-20 修好，之前是穿过箱内的两块实心板），箱子里面整个都能用。

## 摆完之后

把 `.blend` 发回来就行。导进 Unity、挂到容器下面由美术这边来做：位置 0，缩放 0.8，用来抵消 1.25 倍的放大；抽屉的姿势挂在 `Drawer_0` 下面。

## 重新生成

容器尺寸变了就重跑：

```
python -I Assets/_Art/Tools~/pose_reference_boxes.py Assets/_Art/Editor Assets/_Art/Source~/PoseReference
```

尺寸和板厚从 `ContainerPrefabBuilder.cs` 读取；每种容器的结构写在脚本里，要和 `ContainerPrefabBuilder.Build` 保持一致。
