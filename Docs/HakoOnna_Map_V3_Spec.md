## 0. 为什么要重做（V2 的问题）

1. **房间尺寸不真实**：V2 的居間、座敷都是 7.28 × 7.28 m（32 畳），真实民家一般是 8~15 畳。
2. **布局不真实**：V2 用一条中走廊把房间分成两排，像现代公寓。真实老宅是「田の字」格局：房间之间用襖直接相连，入口一侧是一大块土間，外圈有縁側。
3. **楼梯是 bug**：
   - 楼梯底部顶着北墙；台阶是从地面起的实心方块，所以只能从墙那一侧踏上第一级。
   - 玩家 `stepOffset = 0.15`，第一级台阶高 0.21 m，从侧面上不去。
   - 原来的测试直接从台阶上起步，所以没测出来。

## 5. 楼梯（硬性要求）

| | 主階段 | 裏階段 |
|---|---|---|
| 位置（台阶本体） | x 13.05 ~ 14.25（宽 1.2） | x 3.94 ~ 5.14（宽 1.2） |
| 底部 | z 10.01，y 0.55（廊下地板） | z 10.01，y 0（台所土間） |
| 顶部 | z 13.195，y 3.05（二階北廊下） | z 13.195，y 3.05 |
| 级数 | 12 级，每级高 0.208，深 0.265 | 14 级，每级高 0.218，深 0.2275 |
| 坡度 | 约 38° | 约 44°（小于 slopeLimit 50°） |

1. **底部第一级必须朝向开阔地面**：
   - 主階段正对廊下；裏階段正对台所。
   - 底部前方至少留 **1.2 m** 的空地，不能放容器或道具。
2. 上楼方向都是向北；二层到达口朝向北廊下。
3. 台阶模型不要碰撞。碰撞用一块从「底部前方地面」平滑过渡到「二层地板」的斜坡碰撞体。斜坡两端必须和地面、楼板齐平，不能有超过 0.1 m 的台阶。
4. 楼梯两侧和下方：
   - 楼梯侧面用墙或扶手碰撞挡住，不能从侧面卡进去。
   - 楼梯下方的空间封死。

## 6. 高差：土間 ↔ 木地板，庭院 ↔ 縁側

玩家 `stepOffset = 0.15`，0.55 m 的高差必须用斜坡碰撞处理：
- **土間 → 木地板**（玄関、台所通往次の間、居間、縁側、廊下的门）：
  - 外观：一块式台踏板（高 0.275）加木地板边缘，即两级。
  - 碰撞：在土間一侧放一块看不见的斜坡，长 0.8 m，从 y 0 到 0.55，约 35°。
- **庭院 → 縁側**：~~縁側通往庭院的开口~~ 2026-11-18 起这些开口改成关着的玻璃拉门（见第 7 节），
  门外只留一块沓脱石做装饰，不再有斜坡。
- **木地板下方**（架空层）：外圈用深色挡板封住，玩家不能钻进去。
