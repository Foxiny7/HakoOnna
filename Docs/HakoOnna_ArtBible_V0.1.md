风格：写实日式老宅（已确认）
引擎：Unity（URP）、第一人称
程序接口以《程序开发方案 V1.2》第 6 节为准，本文档不改动玩法。

## 1. 总体方向

### 1.1 时代与场所
- 日本乡村的一座独栋木造老宅，昭和后期（1960–80 年代）建成，已经废弃多年。
- 家具和生活用品还留在原位，像是一家人突然消失了一样。
- 恐怖感来自**日常物品的异常**，而不是血腥：抽屉没有关严、被褥还铺着、日历停在某一天。
- 箱女不是这栋房子的“装饰”，房子本身就是她的身体：所有容器都可能是她，所以容器要做得精致、可疑、彼此相似。

### 1.2 写实的边界
- 材质与光照写实（PBR、物理正确的灯光强度）。
- 不追求照片级扫描画质，目标是“可靠的写实”，性能优先，保证 4~6 人联机稳定帧率。
- 不做肢解、内脏等血腥表现。亡骸用布包裹的骸骨表现。

### 1.3 原创要求
- 只借鉴“日式老宅 + 箱中女人”这一题材，**不参考、不还原**桌游原作的插画、角色造型和图形设计。
- 箱女的外观由我们原创设计（见第 6 节）。

## 2. 色彩与光照

### 2.1 色调
| 用途 | 色彩 |
|---|---|
| 主体 | 旧木头的暗褐色、发黄的障子纸、褪色的榻榻米绿褐色 |
| 阴影 | 偏冷的蓝灰，不用纯黑 |
| 光源 | 裸灯泡和行灯的暖橙色，月光的冷蓝色 |
| 强调色 | 极少量暗红（佛龛、和服、Mary 玩偶的衣服），只用于关键物品，帮助玩家在暗处识别 |

### 2.2 光照方案
- 整体低照度。房屋没有电，绝大部分区域只靠月光和玩家的光源。
- **玩家光源（已确认）**：探索者有手电筒。手电是室内的主要光源，月光只负责勾勒窗户和轮廓。手电的玩法细节（是否占格、电量、声音）待定，见开发方案。
- 手电表现：暖白偏黄的老式手电光，窄光束 + 柔和外圈；其他队友的手电光对所有人可见，可以在暗处看到队友的位置。2026-11-19 定：URP 聚光灯强度 25、55°、射程 16 m（房间中间看得清，远处被雾吃掉）。
- 固定光源全部烘焙（房屋不会被破坏，适合烘焙）。动态光源只有手电和猎杀时的特效光。
- 月光从障子和雨户的缝隙射入，形成长条光斑，作为玩家在暗处辨认方向的主要依据。

### 2.3 后处理（URP Volume）
- 色调映射：ACES
- 轻微胶片颗粒、暗角
- 雾：指数平方距离雾 + 局部漂浮灰尘粒子（URP 没有体积雾，用低成本方式替代）。2026-11-19 定：2.5 m 内基本清楚、5 m 雾一半、7.5 m 以外看不清（原写“线性雾”，改成指数平方，过渡更自然）
- **猎杀阶段专用 Volume**：饱和度降低、红色通道略增、暗角加重、轻微镜头畸变。猎杀结束时渐出。

## 3. 场景布局

MVP 阶段使用下面这一张地图（已确认）。

### 3.0 地图变化策略（已确认）
- MVP 阶段：**一张固定地图**，每局只随机内容（物品位置、弱点、秘密出口等，按玩法规则）。
- 核心玩法稳定后：考虑加入**同一张图的预设变体**（部分家具位置每局从几套预设中选），需要先确认对平衡的影响。
- 多张地图留到正式内容扩展阶段。
- 不做完全随机生成的房间。

### 3.1 规模
- 两层木造住宅 + 小院子 + 一间仓库（土蔵）。
- 布局和尺寸以 `Docs/HakoOnna_Map_V3_Spec.md` 为准（V3：田の字格局，京間模数，半间 = 0.91 m）；灰盒场景里平面整体 ×2。适合 3~5 名探索者。
- 容器 45 个、秘密出口候选点 4 个，数量和 V1 相同。
- 门洞宽度为 V3 规格的 1.25 倍（和家具放大比例一致），门楣（鴨居）离地 2.2 m；玩家胶囊体高 1.65 m。
- 只有玄関正门和台所后门（勝手口）通到室外；縁側朝院子的开口是关着的玻璃拉门，竹篱笆把室外分成门前、后院、主庭园三块（2026-11-18 确认）。
- 两层是为了配合“不同楼层”的声音衰减规则。

### 3.2 房间
| 区域 | 房间 | 玩法用途 |
|---|---|---|
| 一层 | 玄関（门厅） | **大门**（路线二出口），开局出生点 |
| 一层 | 土間・台所（厨房） | 容器密集区 |
| 一层 | 居間（起居室） | **保险箱（金庫）** 所在 |
| 一层 | 座敷（客厅）、床の間 | 宽敞，适合猎杀追逐 |
| 一层 | 仏間（佛堂） | **超度地点** [超度方式待定] |
| 一层 | 縁側（檐廊） | 环绕庭院的长廊，追逐环路 |
| 一层 | 風呂・便所 | 狭窄、容器少 |
| 一层 | 納戸（储藏间） | 容器密集区 |
| 二层 | 子供部屋、寝室、物置 | 楼梯是唯一上下通道之一，形成风险点 |
| 屋外 | 土蔵（仓库） | 容器密集区，与主屋隔开 |

- 至少保留两条上下楼的路线（主楼梯 + 一把梯子或后楼梯），避免猎杀时楼梯成为死路。
- 每个房间都有至少两个出口，避免追逐时卡死。

### 3.3 秘密出口
- 设计者已确认：被发现后**掀开地毯**展示出口。
- 视觉方案：铺在榻榻米上的旧地毯（昭和时代常见），下面是一块地板暗门，上面缠着锁链和挂锁。
- 制作 4~6 个**候选位置**，每处都铺地毯；未被发现时所有候选点外观完全相同，地毯下没有暗门模型（暗门在发现时才生成，满足隐藏信息要求）。
- 候选位置数量和生成方式由设计者决定。

### 3.4 废弃感与陈设（2026-11-19 确认）
- **程度：重**。这栋房子荒废了很多年：墙皮、土块、碎纸和旧报纸、碎瓷、枯叶、稻草、灰团、地上的水渍霉斑，天花角的蜘蛛网，
  和室里一扇断了的障子靠在墙上，物置的天花塌了一块，走廊地上掉着一张遗影。细节见 `Assets/_Art/README_美术接入说明.md` 第三轮一节。
- **陈设不能看起来能搜**：装饰用的箱子只做敞开的空箱或明显封死的（绳子、封条、积灰），不做抽屉、柜门这类会让人想打开的东西；
  血字不写在收纳箱上方。能开的只有 45 个容器。
- **防尘布可以盖**（用户：“不用管，玩家发现没有 E 就不会搜了”）：电视、缝纫机、人台、长桌、长凳、座卓这类家具上盖旧布；容器一律不盖。
- **素材**：先用外部 CC0 资源（Poly Haven 的模型和贴图、The Met 开放资源里的古画做屏风和挂轴），实在没有才用代码生成。
- **不要纯色、不要方块拼的家具**（2026-11-20 用户要求）：游戏里每个材质都要有纹理；床、桌椅、被褥、毛巾这类东西不能是几块方块 / 圆柱拼的——先找 CC0 模型，没有的做成有褶皱、鼓起来的软网格，或者倒角、车削的形状。布：素色旧布 + 少量格子；洋床用旧铁床架。
- **便所、風呂**分成小间（前间 / 里间 / 隔间；浴室 / 洗面所 / 脱衣所），新隔墙的门洞挂暖帘、不装门；
  便所隔间的门是能用 E 开关的铰链门（默认开着，房子里唯一不是推拉门的门）。

## 4. 容器

所有容器开启时间相同（玩法已确认），所以**外观大小不同，但交互节奏要一致**。

**开启时序（已确认）**：读条期间容器保持关闭，进度只在 UI 上显示；读条完成后才播放打开动画（约 0.35 秒）；玩家停止交互后播放关闭动画。

| 设计文档类型 | 日式对应物 | 开启方式 |
|---|---|---|
| 衣柜 | 押入れ（壁橱） | 横向推拉的襖门 |
| 衣柜 | 洋服箪笥（西式衣柜） | 双开门 |
| 抽屉 | 箪笥（桐木抽屉柜） | 抽屉拉出 |
| 橱柜 | 茶箪笥（餐具柜） | 推拉玻璃门 / 小门 |
| 储物柜 | 下駄箱（鞋柜） | 单开门 |
| 木箱 | 長持（大木箱） | 掀盖 |
| 收纳箱 | 葛籠 / 行李箱（藤编箱） | 掀盖 |
| 收纳箱 | 米びつ（米柜） | 掀盖 |

### 4.1 视觉规则
- 所有容器在关闭状态下都是**完全关严**的，不能从缝隙看到里面（防止玩家通过画面判断箱女位置）。
- 同一类型做 2~3 个变体（磨损程度、颜色），防止玩家靠外观记住某个容器。
- 每个容器的开口处都有一个统一的黑色内腔，深度足以“看不清”。里面没有藏匿者时，开箱只露出物品。
- 里面有箱女或箱人时，开箱就是死亡，播放 4.3 的开箱死亡演出。藏匿姿势的模型只在服务器确认死亡后生成，平时不放在容器里。

### 4.2 预制体结构（对接程序接口）
```
Container_Tansu_A          ← 程序挂逻辑组件（不修改）
├─ Visual                  ← 美术替换的部分
│   ├─ Body
│   └─ Door / Drawer / Lid ← 由 ContainerVisual.IsOpen 驱动
├─ InteractPoint
├─ ItemAnchor
└─ GrabAnchor
```

### 4.3 开箱死亡演出（2026-11-19 确认，2026-11-21 改成开门就突脸）
适用于普通搜索或深度搜索完成时，容器里有箱女或箱人的情况；对藏有箱女的容器使用错误弱点道具而死亡时也一样（2026-11-19 确认，见下面的规则）。箱女和箱人在同一个容器里时，播放箱女的版本。下面的时长都是 **[待定]**。

**受害者（第一人称）**（2026-11-21 改：门一开她就扑出来，不再先安静地停一下）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0 秒 | 读条完成，门或盖开始打开 | `container_open` |
| 门一打开 | 她立刻突脸：骨头“咔”地掰回原位，头、肩膀和双手冲出开口，头直接冲到探索者面前，张开血盆大口（脸见 6.2），双手抓住探索者的头。藏匿姿势只是这段动画的第一帧，不停留 | `grab` 开头的骨响 |
| 紧接着 | 镜头被往她那边拽，直到她的脸离镜头约 0.2 m。她的身体留在容器里，很多容器她自己够不到站着的玩家，差的距离由镜头补（见下面的“突脸终点姿势”） | — |
| 约 0.6~1.1 秒 | 她的脸占满整个屏幕，两边是她抓住探索者的手（倒着的脸例外：手在画面上方，见下面的“突脸终点姿势”） | — |
| 约 1.1 秒 | 被她抓着拖进容器，直接黑屏 | — |
| 黑屏约 1.5~2 秒 | 一大堆骨头断裂、血肉撕开的声音，就是受害者被折进箱子 | `grab` |
| 之后 | 转化为箱人，原玩家继续控制（玩法规则，不改） | — |

改之前（2026-11-19）：0.35 秒时先一瞬间看到她塞在里面（安静），约 0.5 秒才扑上来。2026-11-21 还试过双手扶着容器、不抓人，当天就改回抓人。

**旁边的人（第三人称）**：同样看得到。门或盖打开，她的头和双手扑出开口，抓住受害者，把人拖进容器，门或盖关上，骨头断裂的声音从容器里传出来。之后容器恢复关闭，看不到里面（与《程序开发方案》2.3 一致）。

**规则**
- 她的身体始终留在容器里（胯不出开口），只有头、肩膀和双手扑出开口，双手抓住探索者把人拖进去。和猎杀时的现形无关。
- 跳脸时脸停在离镜头约 0.2 m，不能被镜头的近裁剪面切掉；镜头碰到容器之前就要黑屏。
- 受害者的手电在演出一开始就被收走（玩法），所以她脸前下方带一盏冷白补光，跟着门开关，不改她纸白的肤色；颜色和亮度 **[待定]**（2026-11-21，接入数值见 `Assets/_Art/README_美术接入说明.md`）。
- 拉人动画里，受害者的身体只能从开口进去，不能穿过柜壁或箱壁。
- 演出期间，容器里的物品在画面上隐藏，避免和藏匿姿势穿模；规则上物品照样留在容器里。
- 箱人的演出流程相同，脸换成箱人的（见 6.3）。
- 跳脸恐怖音效后期再加（见第 7 节）。
- 使用错误弱点道具死亡：同样的演出，只是没有读条，道具效果播完后容器猛地打开。
- 猎杀中被处决的演出：**[待定]**，以后谈猎杀时再定。

## 6. 角色

### 6.1 探索者
- 普通现代人（类似来探险的年轻人），4~5 套外观，便于在黑暗中区分队友。
- 模型身高约 1.70 m（碰撞胶囊 1.65 m）。第一人称镜头高度要从 1.45 m 调到约 1.58 m（2026-11-18 确认，由程序修改 `EyeHeight`）。
- 本地玩家只看到手臂；其他玩家看到全身（程序接口已规定）。
- 探索者死后变成的箱人就用他自己的模型（见 6.3），第三人称的拉人动画也用探索者的骨骼。
- 制作顺序：箱女做完马上做探索者（2026-11-19 确认）。

### 6.2 箱女（2026-11-19 确认）
- 设定：大约 7 岁的小女孩，身高约 1.2 m（与官方设定一致）。
- 外形：
  - 头发（2026-11-20 改）：很长的黑发，垂到胸口以下；湿透发亮，像刚从水里出来，结成粗缕，发梢参差；正中分，像黑色的帘子一样垂在两肩前面和胸前；额前是一缕缕湿的碎发，挂过眼睛、有的贴在皮肤上。不要齐刘海、妹妹头、公主切。
  - 和服（2026-11-20 改）：深红色单层童装和服，颜色还很鲜，只有褶皱和湿的地方发暗；湿重、微微贴身；窄袖软软垂着；细的素色腰带在背后打个小结，不打蝴蝶结；下摆和袖口不规则地撕破、起毛（不要整齐的锯齿边）；光脚，脚底很脏。衣襟左前还是右前：**[待定]**。
  - 皮肤（2026-11-20 改）：纸白、没有血色，带一点冷的灰蓝；脸颊和下巴上有脏污；脸颊凹陷；四肢有很淡的折纸折痕。
  - 眼睛（2026-11-20 改）：乳白色、几乎没有颜色，像死人的眼睛一样发浑，只剩一点淡淡的瞳孔；眼窝很深，四周是烟灰色的阴影，下眼睑微微发红；从不眨眼。（同一天先改成过“瞪大、充血、小瞳孔”，更早是全黑眼睛。）
  - 嘴唇：暗红（酒红），干裂，是脸上唯一的颜色。
  - 表情：平时面无表情，微微低头，从眉骨下面往上冷冷地盯着人；不要可怜、悲伤的样子。只有动起来时才露出又饥渴又急切的样子。
  - 配色：黑发、纸白的皮肤、深红的和服、暗红的嘴唇，她身上没有别的颜色。
  - 手：手指细长、骨节突出，指甲长而脏、有裂口。
  - 氛围参考（2026-11-20，用户提供，只取感觉，不照抄）：两张封面图（湿乱长发、脏污消瘦、扒着木板的细长手指）；一张凝视肖像（中分的湿发帘、乳白的眼睛、纸白的脸、暗红嘴唇、深红和服，冷绿色的低调光，什么都不做只是看着你）。
- 跳脸的脸（开箱死亡特写）：下巴脱臼，嘴张得很大，露出小小的乳牙，缺一颗；嘴里一片血红（“血盆大口”，2026-11-21）；嘴角撕开；脸上一道折纸一样的折痕；发丝糊在脸上；头微微歪着。脸部手工雕刻，头部贴图最高 4K。现在的 Tripo 模型（2026-11-21）嘴是闭着画在贴图上的，没有下巴骨骼，也没有口腔和牙齿，张嘴的做法 **[待定]**。
- 平时看不到。开箱死亡时露出头和双手（见 4.3）；只有猎杀阶段才离开容器、全身现形。
- 现形时从容器中“展开”：先伸出手，再挤出身体，骨头一节一节掰回原位（约 1.5 秒，具体时长由程序决定是否允许打断）。
- 动画需要：8 个藏匿姿势、每个姿势各一段扑出来的突脸动画（两者的第一版姿势 2026-11-21 已摆好，见 4.3）、展开出箱、奔跑（四肢着地与直立两种）、抓捕、拖拽、被击退、被击杀、回到容器。

### 6.3 箱人（2026-11-19 确认）
- 箱人就是死掉的探索者本人：用他自己的探索者模型，保留原来的衣服，身材跟探索者一样（约 1.70 m）。
- 箱人不能离开容器，但开箱死亡时会像箱女一样扑出来（见 4.3），所以需要完整模型，不再只做手。
- 箱人版处理：皮肤蓝灰，眼睛往上翻成白的，下巴脱臼，嘴边一道血；骨头断了，折在容器里。
- 手：跟箱女同一种画法，蓝灰色、没有折痕，大人的尺寸。
- 每种容器一个塞进去的姿势（共 8 个）和扑出来的动画。大人塞进葛籠这种小箱子，只能是骨头全断、折起来的样子。姿势做在探索者共用的骨骼上，每套外观都要过一遍防穿模检查。
- 还需要被消灭时的特效。
- 制作顺序：箱女 → 探索者 → 箱人版和第三人称拉人动画（2026-11-19 确认）。

### 6.5 藏匿姿势防穿模（箱女和箱人通用）
- 在缩放后的真实容器预制体里摆姿势；挂在容器下面的模型要反向抵消 1.25 倍的放大。抽屉的姿势挂在 `Drawer_0` 下面，跟着抽屉动。
- 参照箱（2026-11-20）：`Assets/_Art/Source~/PoseReference/` 里有 8 个 `.glb`，按预制体 × 1.25 生成，带 1.5 cm 安全框、脸的位置和玩家检视镜头，在 Blender 里摆姿势用，用法见那里的 README。生成脚本是 `Assets/_Art/Tools~/pose_reference_boxes.py`，容器尺寸或结构变了要重跑。
- 長持：两道铁箍只贴在箱子前后两面（`Fit_Band`，2026-11-20 改；之前是穿过箱内的实心板），箱内整个空间都能用。
- 摆姿势的脚本（2026-11-21）：`Assets/_Art/Tools~/ghost_pose_lib.py` 和 `ghost_pose_specs.py`，在后台运行的 Blender 5.3 里把箱女模型摆进 8 个参照箱，检查安全框、突脸时手脚有没有穿进板材，渲染玩家视角对照图（`ghost_pose_sheets.py`），存 `.blend`，导出 Unity 用的 FBX（`--fbx`）。进 Unity 后用 `HakoOnnaGhostSetup`（菜单“Hako/Art/箱女：…”）建材质、预制体，出 8 种容器的检查图，并逐根骨头和 Blender 对位置。Tripo 模型的长发原来绑在胯和手臂上，大姿势会把头发扯成一片，所以脚本给头发加了 7 条挂在头上的骨链，并重新蒙皮。
- 关节扭到不可能的角度时，普通蒙皮会塌，每个姿势要单独修形。现在的第一版还没修形：腿分得很开时（下駄箱、洋服箪笥），和服下摆会像膜一样被扯开。
- 美术方的编辑器检查，烘焙每个姿势和每级 LOD：
  - 离墙、盖、门至少 1.5 cm，撑墙的手脚也一样；只允许贴地，不能低于底面。
  - 自己不能穿自己：身体对身体、身体对衣服、头发对身体。
  - 抽样检查扑出来、回去和拉人动画的关键帧。
- 抽屉：叠起来不超过 0.33 m（侧板高 0.347 m），脸要在拉出来的那 0.56 m 里面。
- 米びつ：手扣在边沿下面的内壁，不能扣在边沿上，否则盖子关上会穿模。
- 不做头发和布料物理；删掉衣服下面看不到的身体网格。

## 7. 音频方向（概要）

声音键已由程序接口定义，美术方负责提供素材。
- `grab`（开箱死亡，2026-11-19 确认）：开头一声骨头“咔”地掰回原位，然后是黑屏里一大堆骨头断裂、血肉撕开的声音。受害者在黑屏里听到，旁边的人从容器的方向听到。
- 跳脸恐怖音效：后期，箱女做好后再加。到时需要在《程序开发方案》第 6 节加一个新的声音键。
- `hider_roll`（滚动音效）：最重要的一个声音。要求“像东西在木地板或箱子里滚动”，同时**不能听起来像脚步**，并准备 4~6 个变体避免玩家靠音色判断是箱女还是箱人（两者规则上使用相同音效）。
- 环境音：木头热胀冷缩的咯吱声、风吹雨户、远处虫鸣。注意不要和 `hider_roll` 混淆，否则会干扰玩法判断。
- 猎杀：低频心跳 + 不协和弦乐层，开始和结束时有明确的听觉信号。
